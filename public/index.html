About multiple sources for the same value

Boats often have more than one device reporting the same thing — a chartplotter, a GPS antenna and an AIS transponder may all report position. That is normal and not a fault.

What matters is whether you have told the server which one you prefer. If you haven't, it uses whatever arrived most recently, which can change without warning.

The Data Browser shows every value currently arriving and which sources are producing it. If a value you care about lists more than one source and no priority is configured, that's worth a look.

Open the Data Browser · Priorities are set under Data Connections in the admin UI.
